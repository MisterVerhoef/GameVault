# Security Policy

## Reporting a vulnerability

Please report security problems **privately**. Do not open a public issue or discussion for them.

Use GitHub's private reporting: go to the **Security** tab of this repository and choose
**Report a vulnerability**. If that button is not available, contact the repository maintainer
privately through their GitHub profile.

Include, where you can:

- what the problem is and where it is (file, route or script),
- steps to reproduce it,
- what an attacker could do with it.

## Scope

- The code on the `main` branch.
- The dependencies it uses.

## What to expect

This is a small project maintained in spare time. You will get an answer as soon as possible, and
fixes are prioritised by how serious the problem is. Please give the maintainer reasonable time
to fix the problem before you disclose it publicly.
