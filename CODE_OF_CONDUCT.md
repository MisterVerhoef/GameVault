# Code of Conduct

GameVault follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

We want this project to be a welcoming, harassment-free place for everyone, whatever their
background or experience. When you take part in issues, pull requests, discussions or any other
project space:

- Be respectful and kind, including when you disagree.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and the people using it.

Not acceptable:

- Harassment, insults, or personal or political attacks.
- Sexualised language or imagery.
- Publishing someone's private information without their permission.
- Any other behaviour that would reasonably be considered inappropriate in a professional setting.

## Enforcement

The repository maintainer is responsible for enforcing this code of conduct and may remove,
edit or reject comments, commits, code, issues and other contributions that do not follow it.

To report a problem, contact the repository maintainer privately through their GitHub profile.
Reports will be handled as confidentially as possible.

The full text, including the enforcement guidelines, is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
